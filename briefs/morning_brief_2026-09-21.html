別再把容器查詢當媒體查詢：組件自治時代的響應式思維
Stop Treating CSS Container Queries Like Traditional Media Queries
很多前端開發者仍把 CSS 容器查詢當成另一種螢幕斷點工具，這完全錯失了它的革命性價值。容器查詢的真諦是讓介面「組件自治」：元件不管被丟到側邊欄、彈跳視窗或主版面，都能根據自身容器大小自動變形。這意味著 UI 設計邏輯必須從「全域視窗支配」走向「原子模組自我調適」，設計系統的建構者必須提早升級思維，否則代碼庫只會越來越臃腫。 — Smashing Magazine
Despite widespread browser support, CSS container queries are still frequently misunderstood as replacements for traditional media queries. Container queries fundamentally shift the paradigm toward component autonomy, allowing UI elements to adapt dynamically to their direct context rather than the overall viewport. Embracing this logic enables truly modular, resilient design systems across diverse platforms. — Smashing Magazine
